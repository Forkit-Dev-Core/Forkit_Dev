# Repository instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md).

## Keep the contribution story current

- Use [the Footprints contribution story](https://github.com/Forkit-Dev-Core/footprints/blob/main/CONTRIBUTIONS.md) as the shared history for Footprints and Forkit Core. Keep the founding paragraph crediting Syed Amir Hamza and Arpita Sarker together.
- When a change incorporates public contributor work or changes its status, include the credit and source links in the Core PR, and carry the entry into the shared page in a linked Footprints PR. Write one plain-language line per person, link the original PR or commit, and link the integrating PR or release once available. Credit substantive code, tests, documentation, reports, and reviews when you can verify them from public sources.
- Distinguish merged work, released work, open proposals, and separate prototypes. Preserve original commit authorship and applicable notices when carrying over code. Thank the original contributors in the PR and release notes when their work ships.
